# Student-Marks-Analyzer
A beginner-friendly Python project that analyzes a student's marks and generates a result summary.

## Features

- Takes student name and marks
- Validates marks from 0 to 100
- Calculates total and average
- Calculates percentage
- Generates overall grade
- Shows PASS/FAIL
- Finds highest and lowest marks

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open `student_marks_analyzer.py`.
3. Run the program using Python.
